How to use this list
  1. Read it first. Delete anything you offer. If you sell and install fixtures, keep searches like "faucet installation" running.
  2. In Google Ads, type "negative keyword lists" in the search bar at the top and create a new list.
  3. Paste the searches, one per line, then apply the list to your search campaigns.
